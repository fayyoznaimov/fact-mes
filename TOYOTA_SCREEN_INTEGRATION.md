# Экран Toyota JAT810 из карточки станка

Проверка 15 сентября 2026. Источники: предоставленный пользователем файл `192.168.1.40.jat810` и скриншот открываемой панели. Файл не запускался, подключения к станку не выполнялись.

## Что установлено

- `.jat810` — в данном примере текстовый файл длиной 12 байт. Единственное содержимое — адрес `192.168.1.40`, совпадающий с именем файла. Порта, пароля, режима просмотра и имени запускаемой программы в нём нет.
- На скриншоте заголовок окна `JAT810`, обозначение станка `J10`, меню Operator / Map / Info / Moni / Ext и значок замка.
- Пользователь сообщил, что этот файл открывает показанную панель. Это позволяет подготовить связь адреса с карточкой станка, но перед использованием необходимо сверить идентификатор в справочнике MES. Один скриншот не устанавливает адреса остальных станков.
- В проверенных пользовательских ключах ассоциации `.jat810` и `HKEY_CLASSES_ROOT\.jat810` на текущем компьютере зарегистрированный обработчик не найден. Это не доказывает отсутствие программы: возможны другой компьютер, ручной запуск или другой способ установки.
- Наличие удалённой панели не подтверждает стандартный протокол VNC/RFB, его порт или совместимость с noVNC. Скриншот также не показывает серверные ограничения управления.

## Что полезно сверить по экрану

Все значения относятся только к предоставленному изображению; свежесть снимка и момент измерений неизвестны.

| Видимое поле | Польза для MES | Ограничение |
|---|---|---|
| 528 rpm | Сверка поля скорости из FACT | Не устанавливает, какое из нескольких полей скорости экспорта является фактическим |
| Run time / Stop time | Проверка представления длительности состояния | Сначала подтвердить период и формат; скриншот не является историей переходов |
| Shift B, Efficiency 96.9% / 24H 83.4% | Сверка эффективности и периода | Не называть полной OEE без согласованного расчёта качества |
| Warp / Weft / Other | Диагностика потерь | На скриншоте не указаны единицы этих чисел. Не считать их автоматически количеством обрывов или минутами |
| `1414 / 0 pieces` | Кандидат для сверки производственных счётчиков | Нужно установить смысл обеих частей и момент сброса; не преобразовывать напрямую в выпуск заказа |
| Top / Btm и длительность с датой | Сверка прогнозов по навоям и подготовка замены | Уточнить применимость, формат, источник времени и состояние прогноза при останове |
| `70/481 kgf` | На панели явно видна единица kgf | Не установлены смысл числителя/знаменателя и соответствующее поле FACT; не назначать эту единицу всем данным Tension |
| `200100 TC 390`, PICK, PILE | Дополнительные признаки выполняемой настройки | Требуется сопоставление с техкартой. По подписи нельзя подтвердить заказ 1С |

Экран Toyota нужен инженеру для диагностики и проверки значений. Планирование получает структурированные данные через согласованный сборщик; считывание цифр с изображения не является основным каналом интеграции.

## Предлагаемый пользовательский сценарий

1. В Ганте или карте цеха открыть карточку станка.
2. Нажать «Экран станка»; показать название выбранного оборудования и доступность просмотра.
3. Использовать установленную программу Toyota, если подтверждён её поддерживаемый способ запуска. Встраивание в веб-интерфейс рассматривать только после установления протокола и ограничений доступа.
4. Возвращаться к тому же заданию в MES. VNC/панель не запускается автоматически на всех 20 терминалах.

Для реализации нужен исполняемый файл программы, путь к нему либо её документация. До этого нельзя выдумывать аргументы командной строки, регистрацию протокола, пароль или сетевой порт. Таблица адресов должна быть явной и привязанной к ID станка, с доступом по ролям и участкам. Кнопка интерфейса и значок замка не заменяют проверку режима просмотра на стороне целевого средства подключения.

Исходные `.jat810` и изображение в git не включаются. Правило FACT «только чтение» сохраняется; никаких изменений программ станков, уставок, управления или удалённых клавиатурных событий в этой проверке не было.
