## Ограничение старого адреса 1С

На Windows работает только переадресатор в
`C:\Users\Asus\AppData\Local\FACT-MES-relay\windows_1c_relay.py`.
Его журнал — `relay.log` в том же каталоге; ключи и тела запросов туда не пишутся.
GET/POST `/api/v1/1c` передаются на Linux. Остальные страницы направляют
браузер в Linux; старые открытые вкладки перед редактированием нужно обновить.

Автозапуск Windows не настроен: автоматическая проверка безопасности отклонила
команду его настройки. Простой запуск без изменения автозапуска выполнен.
Пока в 1С используется старый IP, этот Windows-компьютер должен работать.
После его перезапуска переадресатор запускается вручную:

```powershell
Start-Process -WindowStyle Hidden -FilePath 'C:\Users\Asus\AppData\Local\Programs\Python\Python312\python.exe' -ArgumentList 'C:\Users\Asus\AppData\Local\FACT-MES-relay\windows_1c_relay.py --listen 172.0.30.107 --port 8780 --log C:\Users\Asus\AppData\Local\FACT-MES-relay\relay.log'
```

Изменение адреса отправки в 1С на `http://172.0.30.4:8780/api/v1/1c` полностью
уберёт зависимость MES от Windows. Сам Linux уже запускается автоматически.
